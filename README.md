# task-manager — менеджер задач

Учебный проект на Angular: список дел, в котором задачи можно добавлять,
редактировать, отмечать выполненными и удалять. Задачи фильтруются по статусу
и сохраняются в localStorage, поэтому список остаётся на месте после
перезагрузки страницы. Сервер не нужен — всё работает в браузере.

## Технологии

- Angular 20, standalone-компоненты (без NgModule)
- TypeScript
- Reactive Forms — форма добавления задачи с валидацией
- Angular Router — три страницы приложения, одна из них с параметром в адресе
- Сервис с внедрением зависимостей (`@Injectable`, `providedIn: 'root'`)
- Свой pipe и своя директива
- localStorage — хранение задач
- Обычный CSS: по файлу стилей на компонент, flexbox

## Что умеет приложение

- Добавление задачи через форму на Reactive Forms
- Валидация: название обязательное и минимум 3 символа, описание — не длиннее
  200 символов; под формой виден текст ошибки
- Необязательное описание к задаче: видно на её странице, там же его можно
  изменить или стереть
- Отметка задачи выполненной — чекбоксом, название становится зачёркнутым
- Редактирование названия прямо в списке (кнопка «Изменить») — с той же
  проверкой на длину и текстом ошибки под полем
- Удаление задачи с подтверждением, чтобы не стереть её случайно
- Фильтр: все / активные / выполненные
- Страница отдельной задачи по адресу `/tasks/:id`: описание с редактированием,
  статус, номер и кнопка «Отметить выполненной». Открывается кликом по названию
  задачи в списке
- Счётчик оставшихся задач с правильным окончанием: «1 задача», «2 задачи», «5 задач»
- Все изменения сразу сохраняются в localStorage
- Страница «О проекте» и переключение между страницами через роутер
- Адаптивная вёрстка: на узком экране форма перестраивается в столбик

## Как запустить локально

1. Склонировать репозиторий и перейти в папку проекта:

   ```bash
   git clone https://github.com/username/task-manager.git
   cd task-manager
   ```

2. Установить зависимости:

   ```bash
   npm install
   ```

3. Запустить дев-сервер:

   ```bash
   npm start
   ```

   Приложение откроется на http://localhost:4200

Файл `.env` этому проекту не нужен: внешних API здесь нет, данные лежат
в localStorage браузера.

Сборка production-версии — `npm run build`, готовые файлы появятся в папке `dist`.

Нужен Node.js версии 20.19+, 22.12+ или 24+ (требование Angular 20).

## Чему я научился

- Разбивать интерфейс на компоненты и связывать их через `@Input()` и
  `@Output()`: данные идут вниз, события — вверх. Раньше я складывал всё в один
  компонент и потом не мог в нём разобраться.
- Понял, зачем нужны сервисы: вся работа с задачами и localStorage лежит в
  `TaskService`, и компоненты про localStorage вообще не знают. Если завтра
  вместо localStorage появится сервер, менять придётся один файл.
- Разобрался с Reactive Forms: `FormGroup`, `Validators.required` и
  `minLength`, и почему текст ошибки лучше показывать только после `touched` —
  иначе пользователь видит красное сообщение ещё до того, как что-то ввёл.
- Написал свой pipe и свою директиву и наконец понял разницу: pipe меняет
  значение при выводе в шаблон, а директива меняет поведение элемента.
- Понял, что данные в localStorage со временем «стареют»: у задач, добавленных
  до появления описания, поля `description` просто нет. Теперь при загрузке
  подставляю пустую строку, иначе шаблон получил бы `undefined`.
- Столкнулся с тем, что после `filter()` в сервисе получается новый массив, и
  компонент со старой ссылкой ничего не видит. Поэтому после каждой операции
  страница заново забирает задачи у сервиса.

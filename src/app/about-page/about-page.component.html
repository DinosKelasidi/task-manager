О проекте

Это учебный проект на Angular. Приложение помогает вести список дел: задачи можно добавлять, редактировать, отмечать выполненными и удалять.

Что здесь использовано:

  • Standalone-компоненты и передача данных через @Input() и @Output()
  • Reactive Forms с проверкой поля перед отправкой
  • Сервис TaskService, который хранит задачи и пишет их в localStorage
  • Роутинг между списком задач и этой страницей
  • Свой pipe для склонения слова «задача» и своя директива автофокуса

Задачи хранятся только в вашем браузере, на сервер ничего не отправляется.
